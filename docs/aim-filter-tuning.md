# 白点调参指南（人话版）

> WP3.4 交付物（ADR-014）。调的是「瞄准白点」的手感：静止稳不稳、甩动跟不跟手、
> 识别中断时白点滑多久、跳变过滤多严格。
> 改完想验证效果：`swift run ScreenAim --filter-self-test`（确定性合成信号，秒级出数）。

## 先说结构：滤波分两段，各管各的

```
iPhone 识别段（强消抖）          Mac 显示段（轻插值）
ArUco 检出噪声 ──► One Euro 强消抖 ──► 15Hz 上报 ──► 插值平滑 + 跳变门 + 滑行 ──► 白点
                   + 跳变门 + 滑行    （不再重复消抖，否则横扫滞后叠加）
```

- 预设档（`--filter-preset`）**两端一起调**：iPhone 段经 calib 的 `filterPreset`
  字段下发（protocol.md §6），Mac 段直接生效。
- 四个单项旋钮只调 **Mac 显示段**（`--dot-*`），iPhone 段跟预设走。
  要改 iPhone 段单项值：改 `AimFilterPreset.phone`（`Sources/ScreenAimCore/AimCoastFilter.swift`）。

## 预设三档

```bash
ScreenAim --calibrate --serve 9100 --filter-preset stable   # 稳如三脚架
ScreenAim --calibrate --serve 9100 --filter-preset daily    # 日常跟手（默认，可省略）
ScreenAim --calibrate --serve 9100 --filter-preset fast     # 疾速响应
```

| 预设 | 什么时候用 | 什么手感 |
|---|---|---|
| 「稳如三脚架」stable | 演示、精细点击 | 静止白点纹丝不动，跳变几乎不可能甩出去；代价：快速横扫明显拖、断识别只滑 3 帧 |
| 「日常跟手」daily（默认） | 通用 | 静止稳、横扫不拖、断识别滑 5 帧（≈1/3 秒），大多数人不用动它 |
| 「疾速响应」fast | 快速拖拽、大范围甩动 | 横扫紧贴手感、断识别滑 8 帧；代价：静止时能看到轻微抖动，快速移动偶尔带一点跳 |

底层映射（iPhone 识别段 / Mac 显示段，源码 `AimFilterPreset`，逐项可对）：

| 参数 | 稳如三脚架 | 日常跟手 | 疾速响应 |
|---|---|---|---|
| minCutoff（识别段 / 显示段） | 0.6 / 1.2 | 1.0 / 2.0 | 1.6 / 3.0 |
| beta（识别段 / 显示段） | 0.25 / 0.5 | 0.5 / 1.0 | 1.0 / 2.0 |
| 滑行帧数（识别段 / 显示段） | 3 / 3 | 5 / 5 | 8 / 8 |
| 跳变门限 k（识别段 / 显示段） | 1.8 / 1.8 | 2.5 / 2.5 | 4.0 / 4.0 |

## 四个单项旋钮（Mac 显示段）

在预设基础上叠加，例：`--filter-preset daily --dot-coast-frames 8`。

| 旋钮（人话） | 命令行 | 底层参数 | 取值范围 | 往哪边调是什么感觉 |
|---|---|---|---|---|
| 静止时白点有多稳 | `--dot-min-cutoff X` | One Euro `minCutoff` | 0.4–2.0 | 往**低**调：更稳，但慢慢移动开始拖；往**高**调：慢速时识别抖动会透出来 |
| 甩动时有多跟手 | `--dot-beta X` | One Euro `beta` | 0.2–1.5 | 往**高**调：快速移动更贴手，但高速段带点抖；往**低**调：横扫变「肉」 |
| 识别中断后白点继续滑多久 | `--dot-coast-frames N` | `maxCoastFrames` | 0–10 | 调 **0** = 一丢就隐（WP1 前的旧行为）；往**高**调 = 掉检时白点按惯性滑更久（15Hz 下 N 帧 ≈ N/15 秒） |
| 跳变过滤多严格 | `--dot-gate-k K` | `gateK`（0 = 关闭） | 1.5–4.0 / 0 | 往**低**调：几乎不甩，但真实快速移动的第一帧可能被压住；调 **0** = 关掉门限（WP3 前的旧行为） |

## 机制备注（调参时心里有数）

- **跳变门限**不是固定阈值：门限 = k × max(近期预测残差 σ, 2.0pt 下限)。持续快速移动时
  σ 自适应变大、门限自动放宽；单帧跳变恰好被拦 1 帧，下一帧真实样本必然放行
  （拦截后首帧旁路门限），所以真实横扫最多被压 1 帧，不会被压死。
- **断流滑行**按最近低通速度外推，速度半衰期 ≈100ms：手已经停下时白点 2–3 帧内
  刹住，不会匀速冲出屏幕；高速运动中断流，恢复识别时有一次追平步进
  （300pt/s + 3 帧断流实测 ≈54pt），属物理必然——旧行为是白点直接消失再跳出来。
- 静止 σ 现状基准：1280×720 bench 场景（48pt 标记）未滤波 σr 0.171pt →
  滤波后 0.080pt（30Hz 合成时间轴 0.072pt / 15Hz 0.079pt）。调参后跑
  `--filter-self-test` 对比这四个数：静止 σ、跳变偏离、滑行帧数、三档横扫误差。
