# 白点抖动/连续性指标定义与门槛

> 配套 `../scripts/jitter_report.py`（常量与本文一一对应，改门槛改脚本头部常量）。
> 经验门槛基于 2026-08 真机会话实测（15–30Hz 上报、MacBook 屏幕逻辑坐标），
> 设备/屏幕尺寸变化时应重新标定。

## 1. 连续性指标（链路时效）

| 指标 | 定义 | 健康参考 |
|---|---|---|
| dt p50 | Mac 到达间隔中位数 | ≈ 上报周期（66ms @15Hz，33ms @30Hz） |
| dt p95 | 到达间隔 95 分位 | < 150ms（约 2.3× 名义周期） |
| 断流 | dt > 500ms 的段（`GAP_S`） | 次数与累计时长都应有解释（挂起/遮挡/退出） |
| 攒批率 | dt < 5ms 的占比（`BURST_S`） | < 10%；升高 = TLV 发送侧排队 |
| 无瞄准点连段 | 连续 x,y 为空的帧数 run-length | 最长段应有场景解释（转头/遮挡） |

注意：timestamp 是 Mac 侧 `Date().timeIntervalSince1970` 到达时刻（main.swift
`logLocalAim`），**不是**手机采集 PTS。dt 只能衡量"链路 + 调度"时效，
相机端真实帧间隔要看手机侧 `detect_ms` 与 LOCALAIM stdout 日志。

## 2. 静止段抖动（手感"稳"的量化）

- 静止段判定：帧间位移的滚动中位数（窗口 15 帧 ≈ 1s，`STILL_WIN`）< 2pt（`STILL_DISP_PT`）。
  用中位数而不用均值——对跳变离群免疫。
- 统计量：剔除跳变帧后的帧间位移 RMS / p50 / p95。
  **RMS 必须剔跳变**：实测静止段内一个 5 万 pt 离群可把 RMS 从 2.4pt 拉到 64pt。
- 健康参考（MacBook 逻辑坐标下）：p95 < 3pt 纹丝不动；3–5pt 可感知轻微颤动；
  \> 5pt 明显抖。

## 3. 跳变事件

- 判定：位移 > max(20pt, 8 × 滚动 MAD)（`JUMP_MIN_PT` / `JUMP_MAD_K`）。
  绝对下限 20pt 滤掉手抖；MAD 门限自适应运动段（快速横扫时 MAD 大，不误报）。
- 读法：
  - 万 pt 级 + markers=4–5 → 4 标记刚好够单应时的退化翻转（坐标系镜像/外推甩飞），
    查 ids 列缺了哪个标记，对应屏幕哪个角的遮挡/反光。
  - 百 pt 级密集出现 → 掉检恢复后的追平步进或 gateK 过宽。
  - 跳变落点聚在固定屏幕位置 → 该处标记误检（相似图案干扰）。

## 4. 功率谱（最长静止段，≥64 帧才做）

- 采样率用段内 dt 中位数现估（`fs = 1/median(dt)`），不按名义 15Hz 写死——
  实测存在 30Hz 上报的会话。
- 频带解读：
  - > 3Hz：ArUco 检出噪声，One Euro minCutoff 的主战场；
  - 0.5–3Hz：手 physiological tremor（8–12Hz 在 15–30Hz 采样下欠采样，别太当真）；
  - < 0.5Hz：真实漂移/缓慢移动/滑行衰减，滤波压不掉，是信号。
- 对比实验时看"高频段功率下降多少"比看单点数值更有意义。

## 5. 分 quality 分层（新客户端数据）

| quality | 含义 | 抖动期望 |
|---|---|---|
| homography | ≥4 标记单应，正常输出 | 基准分布 |
| affine | 降级仿射（标记不足但可近似） | 位移分布可略宽，但不应出现大跳变 |
| coast | 断流滑行外推 | 应平滑单调；若抖 = 速度外推不稳 |

旧 CSV 无此列时脚本自动跳过；分层对比必须新旧客户端口径一致。
